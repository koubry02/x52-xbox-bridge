Game layouts

Press the layout-switch button on the throttle (default BTN_BASE4, the lower half of the first T-rocker) to cycle these in order — or activate one here. The active game shows on the throttle screen as its short name.
edit
Only what you set here overrides the inherited layout. Leave a field/row out to inherit it. Values shown greyed in the resolved preview come from the parent.

Axes

evdev axistargetinvertdeadzone expobutton lowbutton highthreshold
target split_lt_rt = forward half of the axis → RT, back half → LT (AC7-style throttle). button low/high press an Xbox button when the axis passes ±threshold (e.g. twist → LB/RB).
